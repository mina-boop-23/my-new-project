# Regenerative Medicine & Organ Donation Seminar Landing Page

## Description
A clean, responsive single-page landing website developed for the academic seminar "New Challenges in Organ Donation and Transplantation: Novel Horizons and Tools" held at Razi University. This website presents event details, outlines the key topics and tracks, and guides attendees to easily complete their registration.

## Features
- **Engaging Hero Section:** Designed with an impactful headline and a prominent Call-to-Action (CTA) button for quick registration.
- **Medical & Academic Color Palette:** Styled using navy blue, turquoise, and cyan tones to match the event's identity.
- **Fully Responsive Layout:** Optimized across mobile, tablet, and desktop viewports using CSS Grid and Flexbox.
- **Registration Form:** A dedicated section capturing participant details cleanly.
- **RTL & Persian Typography Support:** Properly formatted for right-to-left layout and clear Persian text hierarchy.

## Requirements
- A modern web browser (Google Chrome, Mozilla Firefox, Safari, or Microsoft Edge).
- Python and Django

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mina-daneshi/regmedsummit.git
   ```

2. Navigate to the project folder:
```bash
cd regmedsummit
```

3. Install python and the required packages
```bash
pip install -r requirements.txt
```

4. migrate the database:
```bash
python manage.py migrate
```

5. run with Django:
```bash
python mange.py runserver
```

6. open browser and navigate to `http://localhost:8000`
